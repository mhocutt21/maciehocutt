MACIE PORTFOLIO - INDIVIDUAL ELEMENTS

Each numbered folder contains separately labeled visual regions from the corresponding Canva PDF page.

IMPORTANT: The PDF is not the original Canva layered project. The labeled PNG crops include their original cream or striped backgrounds and sometimes nearby overlapping elements. These are exact visual crops (not edited or recreated), but are NOT transparent, fully isolated Canva layers.

Original_Embedded_Image files are native embedded image assets extracted directly from the PDF (some may include Canva image masks or transformations).

For pixel-perfect, individually movable TRANSPARENT text, stickers, labels and shapes, export them directly from Canva by selecting each element/group and downloading PNG with transparent background, or share the editable Canva project.
