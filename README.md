# Macie Hocutt Portfolio Website

A responsive, scrapbook-inspired portfolio website built with HTML, CSS and JavaScript.

## GitHub Pages setup
1. Create a GitHub repository (for example, `macie-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `images` folder to the **root** of the repository.
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Your website will appear at `https://YOUR-USERNAME.github.io/macie-portfolio/`.

## Edit content
- Change text, experience, links and project cards in `index.html`.
- Adjust fonts, colors and layout in `style.css`.
- Replace photos in `images/` with your own images using the same filenames, or update image `src` paths.
- Project cards are currently **placeholders**, not completed case studies. Add your actual screenshots, work examples and results before publishing as a finished portfolio.
- No build tools or dependencies required. Google Fonts require internet access.

The two photos were cropped from the original PDF design; other scrapbook elements are recreated with CSS rather than extracted as transparent layers.
